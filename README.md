# analytics-platform
Trabajo práctico de DataOps con DuckDB, dbt y Dagster.
## Entorno validado
Este tutorial fue validado con:
- Python 3.12.10
- dbt Core 1.11.9
- Dagster 1.13.3
## Objetivo
Construir un pipeline de datos con enfoque medallón:
Landing → Bronze → Silver → Gold

El resultado final será una tabla con la cantidad de clientes por código postal.
